# Заметки по архитектуре и разработке (dn1sup_ext_manager)

Репозиторий: [dn1test/dn1sup_ext_manager](https://github.com/dn1test/dn1sup_ext_manager)
Менеджер (каталог, установка, обновление) расширений SketchUp через GitHub Releases.

---

## Ключевые архитектурные принципы

1. **Формат пакета .rbz**:
   - Стандартный zip-архив: в корне располагается loader `<id>.rb`, рядом папка `<id>/` с исходным кодом расширения.
   - Постоянная прямая ссылка на актуальный пакет:
     `https://github.com/dn1test/dn1sup_ext_manager/releases/latest/download/dn1sup_ext_manager.rbz`
2. **Минимальный реестр [registry.json](registry.json)**:
   - Каждая запись — только `id`, `name`, `repo`: этого достаточно для каталога, скачивания и обновлений.
   - Версии, описания, changelog'и и `.rbz`-ассеты хранятся в репозиториях
     соответствующих расширений и берутся менеджером из их GitHub Releases.
3. **Безопасность и неблокирующий UI**:
   - Все сетевые вызовы выполняются в изолированных потоках через `defer_async`.
   - Сетевые таймауты `Net::HTTP` ограничены 4–6 секундами для защиты от подвисания при плохой связи.
   - Фоновые проверки не вызывают модальных окон, используя неблокирующие `UI::Notification` (SU2017+).
4. **Установка**:
   - Выполняется через нативный `Sketchup.install_from_archive(path, false)`.
   - Неподписанные RBZ в SketchUp 2017+ вызывают стандартное системное предупреждение о доверенном источнике — это штатное поведение для сторонних расширений вне Extension Warehouse.
5. **Панель инструментов**:
   - Кнопка вызова каталога создаётся один раз (`UI::Toolbar` нельзя удалить через API);
     дубликаты после перезагрузки кода отсекаются проверкой tooltip.
   - Иконка: SVG (SketchUp 2020.1+), fallback — PNG 16/24 (`tools/make_icons.rb`).
6. **Внешние репозитории расширений**:
   - Исходники других расширений DN1Sup хранятся и собираются в их собственных
     репозиториях (`dn1test/dn1sup_*`); здесь ведётся только реестр каталога.
7. **Интерфейс на Vue 3 (v0.5.0)**:
   - Исходники UI — в `frontend/` (Vue 3 + Vite + Tailwind, `vite-plugin-singlefile`);
     сборка `npm run build` кладёт единый HTML-бандл в `src/dn1sup_ext_manager/html/index.html`
     (`emptyOutDir: false`, dev-исключение `frontend/` в pack.rb).
   - Мост Ruby ↔ JS: один экшен-колбэк `call_ruby` (имя команды + JSON-параметр),
     диспетчер `ExtManager.dispatch`; Ruby пушит в UI `window.pushState` /
     `window.pushResult` — единый паттерн с dn1sup_create_project / dn1sup_save_settings.
   - JS error hook (error/unhandledrejection → `log_js_error`) инжектится со
     стороны Ruby при `ready` — без пересборки фронтенда.
   - Вне SketchUp (`npm run dev` в браузере) работает mock-режим (`mocks.js`).
8. **Логирование (v0.6.0)**:
   - `Dn1sup::Updater.log_error` — `[ERROR]`-строки (исключение + backtrace 5 строк);
   - `Dn1sup::Updater.log_info` — `[INFO]`-события: команды каталога (`ExtStore:`),
     ответы GitHub (`latest_release(repo): OK vX / HTTP …`), установка/удаление,
     сводки опросов; записи через Mutex (потокобезопасно);
   - файл `Sketchup.temp_dir/dn1sup_updater.log`, ротация при >1 МБ в `.old`.

## Статус задач и проверок

### Реализовано и закрыто

- **Кнопка тулбара с иконкой (v0.4.0)**: `UI::Command` + `UI::Toolbar`, SVG/PNG иконки из `icons/`.
- **Каталог на индивидуальных репозиториях**: версии/changelog/ассеты — динамически из релизов `dn1test/dn1sup_*`.
- **Удаление шифрования/обфускации Ruby-логики**: пакеты `.rbz` собираются с открытыми чистыми `.rb` исходниками.
- **Мгновенная загрузка Extension Store**: каталог мгновенно рендерится из встроенного кэша `registry.json` (0 мс); сетевой опрос версий изолирован в поток без вызовов SketchUp API; кнопка «Повторить» и страховочный таймаут.
- **Единое меню DN1SUP**: синглтон-метод `Dn1sup.common_menu` (без глобальных переменных `$`).
- **Ребрендинг префиксов (v0.3.1)**: полный переход с `dn1code_` / `dn1c_` на `dn1sup_`.
- **Безопасность UI и мостов**: сериализация через `JSON.generate`, делегированные слушатели `data-action`/`data-id`, нативное подтверждение удаления, запрет самоудаления Store.

## Отложенные задачи и ограничения

1. **Динамический рендер списка в Store**:
   - При повторном обновлении статусов карточек выполняется повторный рендер списка; положение скролла может сбрасываться при некоторых сценариях переключения.
2. **Сертификаты и подписи**:
   - Пакеты распространяются напрямую через GitHub Releases; для снятия предупреждения SketchUp требуется официальная цифровая подпись Trimble Extension Warehouse.
