# Заметки по архитектуре и разработке (sketchup-dn1sup-extensions)

Репозиторий: [dn1test/sketchup-dn1sup-extensions](https://github.com/dn1test/sketchup-dn1sup-extensions)  
Дистрибуция, каталог и механизм автообновления для расширений SketchUp через GitHub Releases.

---

## Ключевые архитектурные принципы

1. **Формат пакета .rbz**:
   - Стандартный zip-архив: в корне располагается loader `<id>.rb`, рядом папка `<id>/` с исходным кодом расширения.
   - Постоянная прямая ссылка на актуальный пакет:
     `https://github.com/dn1test/sketchup-dn1sup-extensions/releases/latest/download/<id>.rbz`
2. **Источник версий — [registry.json](registry.json)**:
   - Каждое расширение имеет независимый номер версии.
   - [Dn1sup::Updater](shared/dn1sup_updater.rb) опрашивает GitHub raw `registry.json` для точной проверки актуальности каждого расширения, а общий тег релиза GitHub (`releases/latest`) используется только как резервный канал.
3. **Безопасность и неблокирующий UI**:
   - Все сетевые вызовы выполняются в изолированных потоках через `defer_async`.
   - Сетевые таймауты `Net::HTTP` ограничены 4–6 секундами для защиты от подвисания при плохой связи.
   - Фоновые проверки не вызывают модальных окон, используя неблокирующие `UI::Notification` (SU2017+).
4. **Установка**:
   - Выполняется через нативный `Sketchup.install_from_archive(path, false)`.
   - Неподписанные RBZ в SketchUp 2017+ вызывают стандартное системное предупреждение о доверенном источнике — это штатное поведение для сторонних расширений вне Extension Warehouse.
5. **Внешние репозитории и сборка**:
   - Внутри монорепозитория в папке `src/` хранится только сам Extension Store ([dn1sup_ext_manager](src/dn1sup_ext_manager)).
   - Остальные целевые расширения разрабатываются в отдельных внешних каталогах:
     - `../dn1sup_autoselect_tag`
     - `../dn1sup_comp_add_view`
     - `../dn1sup_create_project`
     - `../dn1sup_time_project2`
   - Сборщик [tools/pack.rb](tools/pack.rb) упаковывает `.rbz` напрямую из рабочих папок, фильтрует dev-файлы (`test`, `archive`, `.git`, `node_modules`, `frontend`), считывает актуальные версии из лоадеров и синхронизирует [registry.json](registry.json).

## Статус задач и проверок

### Реализовано и закрыто (v0.2.1 — v0.5.1)

- **Удаление шифрования/обфускации Ruby-логики**:
  - Функционал шифрования (`tools/protect.rb`, `AES-256-CBC` + `zlib`) полностью удалён из процесса сборки и репозитория.
  - Пакеты `.rbz` собираются с открытыми чистыми `.rb` исходниками.
- **Хранение статистики в файле модели (dn1sup_time_project2 v2.4.0)**:
  - Статистика активного времени работы сохраняется непосредственно внутри файла модели (`.skp`) через словарь атрибутов SketchUp (JSON), что гарантирует портативность данных при копировании и отправке файлов.
  - Реализована автоматическая бесшовная миграция существующих данных из `stats.yaml`.
- **Единое меню DN1SUP и относительные пути (v0.4.0)**:
  - Все расширения используют единое меню `Extensions → DN1SUP` без дублирования через синглтон-метод `Dn1sup.common_menu` (без использования глобальных переменных `$`).
  - Все абсолютные и глобальные пути к проектам заменены на относительные.
- **Мгновенная загрузка Extension Store (v0.2.3 / v0.3.0)**:
  - Устранено зависание («вечный спиннер»): каталог мгновенно рендерится из встроенного кэша `registry.json` (0 мс).
  - Сетевой опрос версий изолирован в поток без вызовов SketchUp API.
  - В HTML-интерфейсе добавлены кнопка «Повторить» и страховочный таймаут.
- **Внешние источники и чистка репозитория (v0.3.2)**:
  - Исходники внешних расширений удалены из `src/`, исключено дублирование.
  - Сборщик `tools/pack.rb` автоматизирован для сборки из локальных директорий.
- **Ребрендинг префиксов (v0.3.1)**:
  - Полный переход с `dn1code_` / `dn1c_` на `dn1sup_` во всех пространствах имён, константах, идентификаторах, меню и путях.
- **Очистка состава расширений (v0.3.0)**:
  - Демо-плагины (`cube_tools`, `scene_tools`) удалены из репозитория, тестов и реестра.
  - В каталоге зафиксированы 5 целевых расширений: `dn1sup_ext_manager`, `dn1sup_create_project`, `dn1sup_time_project2`, `dn1sup_autoselect_tag`, `dn1sup_comp_add_view`.
- **Безопасность UI и мостов (v0.2.1)**:
  - Устранена потенциальная инъекция в `execute_script` (все параметры сериализуются через `JSON.generate`).
  - Убраны `onclick` в HTML-шаблоне, переведено на делегированные слушатели `data-action` / `data-id`.
  - Подтверждение удаления переведено на нативный `UI.messagebox(MB_YESNO)` по мосту.
  - Запрещено случайное удаление Extension Store из собственного интерфейса.

## Отложенные задачи и ограничения

1. **Динамический рендер списка в Store**:
   - При повторном обновлении статусов карточек выполняется повторный рендер списка; положение скролла может сбрасываться при некоторых сценариях переключения.
2. **Конкурентная запись в time_project2**:
   - При одновременном запуске нескольких независимых экземпляров SketchUp над одним и тем же проектом нет межпроцессного слияния статистики (в рамках одного сеанса данные защищены).
3. **Сертификаты и подписи**:
   - Пакеты распространяются напрямую через GitHub Releases; для снятия предупреждения SketchUp требуется официальная цифровая подпись Trimble Extension Warehouse.
