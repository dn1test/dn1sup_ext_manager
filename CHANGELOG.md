# Changelog (Лог изменений)

Все заметные изменения в расширениях проекта документируются в этом файле с разбивкой по каждому расширению.
Формат версий соответствует правилам `MAJOR.MINOR.PATCH`.

## [0.5.0] — 2026-10-05

### DN1Sup Time Project 2 (v2.4.0)
- **Хранение статистики в файле модели (.skp)**:
  - Статистика активного времени работы теперь сохраняется непосредственно внутри файла модели SketchUp (через `model.set_attribute('dn1sup_time_project2', ...)` в формате JSON) вместо внешнего файла `stats.yaml`.
  - Автоматическая бесшовная миграция: при первом открытии файла существующая статистика из `stats.yaml` импортируется в модель без потери истории.
  - Надёжность и портативность: статистика теперь гарантированно перемещается вместе с файлом модели при отправке, копировании или переименовании проекта.
  - Обновлён интерфейс и индикаторы статуса модели.
- **Синхронизация каталога и релизных пакетов**:
  - Обновлены `registry.json` и встроенный кэш `src/dn1sup_ext_manager/data/registry.json`.
  - Пересобраны актуальные `.rbz` пакеты в директории `packages/`.

## [0.4.0] — 2026-10-05

### Единое меню DN1SUP и отказ от глобальных переменных
- **Единое меню без дублирования**:
  - Все 5 расширений DN1Sup добавляют свои пункты в единое подменю `Extensions → DN1SUP`.
  - Структура: `Extensions → DN1SUP → {AutoSelect Tag, Comp Add View, Export PDF 2, Extension Store, Time Project 2}`.
- **Отказ от глобальных переменных (`$dn1sup_common_menu` / `$dn1sup_menu`)**:
  - Архитектурное соглашение переведено на чистый паттерн Ruby — синглтон-метод `Dn1sup.common_menu` в корневом пространстве имён `Dn1sup`.
  - Полное соответствие требованиям Trimble Extension Warehouse и RuboCop SketchUp (нет загрязнения глобальной области видимости `$`).
  - Сохранена обратная совместимость: если у пользователя уже загружена старая версия одного из плагинов с глобальными переменными, `Dn1sup.common_menu` прозрачно подхватывает существующее меню без создания дубликата.
- **Обновления в расширениях**:
  - **DN1Sup AutoSelect Tag (v0.3.0)**: меню перенесено внутрь `DN1SUP → AutoSelect Tag`; флаг создания подменю переведён с глобала `$dn1sup_menu_autoselect_tag` на инстанс-переменную модуля `@menu_autoselect_tag`.
  - **DN1Sup Extension Store (v0.3.0)**: меню менеджера размещено в `DN1SUP → Extension Store` через `Dn1sup.common_menu`.
  - **DN1Sup Time Project 2 (v2.3.0)**: переход на `Dn1sup.common_menu`; защита от дублирования пунктов при hot reload изолирована внутри `Dn1sup` без использования `$dn1sup_tp2_menu`.
  - **DN1Sup Component Add View (v1.3.0)**: переход на `Dn1sup.common_menu` вместо `$dn1sup_common_menu`.
  - **DN1Sup Export PDF 2**: подменю `Export PDF 2` строится поверх общего `Dn1sup.common_menu`.
- **Автотесты и сборка**:
  - В `test/new_extensions_mock_test.rb` добавлены проверки инициализации `Dn1sup.common_menu` и отсутствия `$dn1sup_common_menu` / `$dn1sup_menu` в глобальной области.
  - Обновлены `registry.json` и `data/registry.json`, пересобраны и синхронизированы все пакеты `.rbz` в директории `packages/`.

## [0.3.3] — 2026-10-04

  - Версия `dn1sup_ext_manager` повышена до `0.2.3` в лоадере, реестре и интерфейсе.
  - Обновлён пакет `dn1sup_ext_manager.rbz`.

## [0.2.1] — 2026-10-03

### Общее (dn1sup_updater, все расширения)
- **Исправлен вечный цикл обновлений**: актуальная версия расширения теперь берётся из `registry.json` (поле `version` конкретного расширения), а не из общего тега релиза монорепозитория. Тег остаётся fallback при недоступном реестре.
- `norm_version` отбрасывает pre-release/build-суффиксы: `v0.3.0-rc1` больше не считается новее `0.3.0`.
- Фоновая проверка обновлений выполняет сеть в отдельном потоке — главный поток SketchUp не замерзает (`Dn1sup::Updater.defer_async`).
- Фоновая (незапрошенная) проверка показывает ненавязчивое уведомление `UI::Notification` вместо модального YES/NO-диалога (до трёх подряд при старте SketchUp). По кнопке меню — прежний диалог.
- Убран двойной диалог установки: `Sketchup.install_from_archive(path, false)` + собственное сообщение.
- Ошибки updater'а пишутся в лог-файл `Sketchup.temp_dir/dn1sup_updater.log` (с ротацией), а не глотаются молча.

### dn1sup_ext_manager (v0.2.1)
- **Исправлено определение установленной версии**: приоритет у фактической версии из Extension Manager; сохранённый при установке тег — только fallback. Ранее тег монорепо «v0.2.0» навсегда маскировал обновления расширений 0.1.0.
- При установке через каталог сохраняется per-extension версия из реестра, а не тег релиза.
- Устранена JS-инъекция через `id` в `execute_script` (все строки — через `JSON.generate`); inline-`onclick` заменены на `data-action`/`data-id` + делегированные обработчики.
- Подтверждение удаления — через нативный `UI.messagebox(MB_YESNO)` по мосту (`window.confirm` в HtmlDialog на части сборок подавлен).
- Запрещено самоудаление Extension Store из самого каталога.
- Сбор данных каталога (до 4 запросов к GitHub API) уходит в фоновый поток.
- `load_registry` больше не показывает модальные диалоги (может вызываться из фонового потока).

### dn1sup_scene_tools (v0.1.1)
- Исправлена высота меток сторон света: `z = 1000` дюймов (≈25,4 м) → 1 м, согласовано с константой `size`.

### dn1sup_cube_tools (v0.1.1)
- Правки общего updater'а (см. «Общее»).

### dn1sup_time_project2 (v0.1.1)
- **Защита от потери статистики**: при неудачной записи `stats.yaml` накопленное сохраняется в памяти и дописывается при следующих flush; при залоченном файле — отложенное чтение с мерджем истории вместо затирания.
- Атомарная запись `stats.yaml`: `File.rename` поверх существующего (MoveFileEx REPLACE_EXISTING) без окна между `delete` и `rename`.
- Ошибка доступа к файлу (лок антивируса/второго SketchUp) больше не отправляет файл в карантин `*.broken-*` — только реальный битый контент.
- Наблюдатель сохранения подключается по объекту модели (identity), а не по переиспользуемому `object_id`.
- Доначисление хвоста при сохранении не работает на паузе; `session_seconds` не обнуляется при первом сохранении.
- Порог разрыва тика (`MAX_GAP`) привязан к порогу бездействия: кратковременная блокировка главного потока не отбрасывает рабочее время.
- Счётчик в диалоге инкрементирует статистику только выбранного = текущего проекта (ранее накручивал чужую карточку).
- Dev-инструменты (`dev_updater.rb`, `test/`, `.sketchup_dev.json`, `README.md`) исключены из релизного `.rbz`; dev-пункты меню показываются только при найденной dev-папке.
- Исправлен маппинг версии SketchUp в dev_updater (`26` → `2026`, без создания мусорных каталогов).

### Инфраструктура
- `release.yml`: Ruby 3.2 (как встроенный Ruby SketchUp), `GITHUB_TOKEN` передаётся в smoke-тесты (лимиты API на shared-раннерах).
- `tools/pack.rb`: исключение dev-файлов из `.rbz`, внятная ошибка при отсутствии `zip`/`rubyzip`.
- `test/live_github_test.rb`: динамические ожидания (тег по паттерну, версия из registry.json) вместо захардкоженного `v0.1.0`.
