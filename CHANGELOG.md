# Changelog (Лог изменений)

Лог изменений **DN1Sup Extension Store** (`dn1sup_ext_manager`).
Формат версий соответствует правилам `MAJOR.MINOR.PATCH`.

Изменения остальных расширений DN1Sup документируются в их собственных
репозиториях (`dn1test/dn1sup_*`); этот репозиторий хранит только реестр
каталога (`registry.json`: id/name/repo), необходимый для установки и обновлений.

## [0.6.1] — 2026-10-07

### DN1Sup Extension Store (v0.6.1)
- **Прикладной лог в приложении сделан кратким** (`Sketchup.temp_dir/dn1sup_updater.log`):
  остаются только ключевые события — открытие каталога, результат установки/
  обновления/удаления расширений и ошибки (`[INFO]` / `[ERROR]`).
- **Подробные записи убраны из прикладного лога в dev-режим**: каждая команда UI,
  каждый запрос релиза, отрисовка каталога и ход скачивания теперь пишутся на
  уровне `[DEBUG]` и появляются только при включённом флаге
  `Sketchup.write_default('Dn1supUpdater', 'debug', true)` (см. README «Dev-режим»).
- Подробная история изменений остаётся в [CHANGELOG.md](CHANGELOG.md) и релизах GitHub.

## [0.6.0] — 2026-10-07

### DN1Sup Extension Store (v0.6.0)
- **Информационное логирование** (`Dn1sup::Updater.log_info`): ключевые события
  каталога теперь видны в ` Sketchup.temp_dir/dn1sup_updater.log` с меткой
  `[INFO]`, ошибки — с меткой `[ERROR]` (ранее в лог попадали только ошибки без
  контекста и without событий Store):
  - открытие каталога, отдача локального снапшота (число продуктов);
  - каждая команда интерфейса (`ready`, `refresh`, `install`, `update`, …);
  - запросы релизов по каждому репозиторию (`latest_release(repo): OK v…` / HTTP-код);
  - сводка опроса (сколько релизов получено), установка/удаление с результатом.
- **Потокобезопасность лога**: запись через Mutex (фоновые потоки + главный).
- `tools/pack.rb` синхронизирует общие файлы из `shared/` и в dev-копию
  `src/dn1sup_ext_manager/` (ранее — только в архив).
- `latest_release(repo)`: в лог пишется запрос по каждому репозиторию
  (`OK v…` / HTTP-код ошибки) — подробности видны в dev-режиме (см. [0.6.1]).

## [0.5.0] — 2026-10-07

### DN1Sup Extension Store (v0.5.0)
- **Интерфейс каталога переписан на Vue 3**: исходники — в `frontend/`
  (Vite + Tailwind + `vite-plugin-singlefile`), сборка одним файлом
  (`npm run build`) кладётся в `src/dn1sup_ext_manager/html/index.html`.
- **Единый мост Ruby ↔ JS**: один экшен-колбэк `call_ruby` (имя команды +
  JSON-параметр) вместо набора отдельных колбэков; состояние и результаты
  операций пушатся в UI через `window.pushState` / `window.pushResult`.
- **Перехват ошибок интерфейса**: JS error hook (`error` /
  `unhandledrejection`) отправляет ошибки в журнал Ruby (`log_js_error`) —
  ошибки Vue/JS видны в `dn1sup_updater.log`.
- **Mock-режим фронтенда**: `npm run dev` в браузере работает без SketchUp
  (мок-данные каталога и операций).

## [0.4.1] — 2026-10-07

### DN1Sup Extension Store (v0.4.1)
- **Исправлена потеря версий и changelog'ов после сетевого сбоя**: неудачный
  запрос релиза больше не кэшируется как `{}` — ранее одна сетевая ошибка
  (OpenTimeout) обнуляла версии и логи изменений в каталоге до конца сессии.
- **Однократный автоповтор** запросов релизов, если сеть была недоступна в
  момент первого обхода каталога.
- **Офлайн-снапшот релизов**: последние успешные данные (версия, changelog,
  дата) сохраняются в temp-каталог SketchUp (`dn1sup_ext_releases.json`) и
  отображаются при следующем открытии каталога без сети. Установка/обновление
  всегда делает свежий сетевой запрос.

## [0.4.0] — 2026-10-07

### DN1Sup Extension Store (v0.4.0)
- **Кнопка на панели инструментов**: каталог открывается кнопкой с иконкой
  (SVG + PNG 16/24/32, генерация — `tools/make_icons.rb`). Дубликаты кнопки
  после перезагрузки кода отсекаются по tooltip.
- **Каталог привязан к индивидуальным репозиториям**: версии, описания,
  changelog'и и .rbz-ассеты берутся динамически из релизов `dn1test/dn1sup_*`;
  в `registry.json` хранится только id/name/repo.
- **Удалены данные других расширений** из менеджера: mock-данные каталога
  заменены нейтральным демо, legacy-костыли (`dn1sup_comp_add_view`,
  `ComponentAddViews`) убраны, тесты расширений перенесены в их репозитории.

## [0.3.3] — 2026-10-04

### DN1Sup Extension Store (v0.2.3)
- **Устранено зависание («вечный спиннер») при открытии каталога**:
  - Каталог отображается мгновенно (0 мс) из локального кэша `registry.json` без ожидания ответа от GitHub API.
  - Потокобезопасность: сетевой опрос GitHub вынесен в изолированный поток без вызовов API SketchUp.
  - Сокращены таймауты сетевых запросов `Net::HTTP` до 4-6 с для предотвращения блокировок при нестабильном интернете.
  - Добавлен страховочный таймаут и кнопка «Повторить загрузку» в HTML-интерфейсе.

## [0.2.1] — 2026-10-03

### dn1sup_ext_manager (v0.2.1)
- **Исправлено определение установленной версии**: приоритет у фактической версии из Extension Manager; сохранённый при установке тег — только fallback.
- Устранена JS-инъекция через `id` в `execute_script` (все строки — через `JSON.generate`); inline-`onclick` заменены на `data-action`/`data-id` + делегированные обработчики.
- Подтверждение удаления — через нативный `UI.messagebox(MB_YESNO)` по мосту (`window.confirm` в HtmlDialog на части сборок подавлен).
- Запрещено самоудаление Extension Store из самого каталога.
- Ошибки updater'а пишутся в лог-файл `Sketchup.temp_dir/dn1sup_updater.log` (с ротацией).
- Фоновые проверки не блокируют главный поток SketchUp (`defer_async`) и используют ненавязчивые `UI::Notification`.
